# サイト全体の評価と改修内容

評価日：2026年9月9日。対象：ユーザー提供 `crewascentimproved (3).zip` と `クルーアセント_事業とサイトの最終情報 (1).md`。

## 総評

元サイトの強みは、無料のWeb診断36で希望を整理してから制作につなぐ、押しつけの少ない事業設計です。36タイプの詳細データや、作業範囲を開示する姿勢も資産です。一方、無料相談が実際に届く仕組みが未接続で、運用機能と公開条件は制作途中でした。説明の密度に対して、相談までの道筋と主要ページの情報の優先順位を整える余地がありました。

今回の目標は「高価格に見せる装飾」ではなく、見た目・内容・操作・運用の一貫性を高めることです。制作費1,000万円という市場価値を保証したり、同額の制作会社案件と同等だと客観的に認定したりするものではありません。実際の顧客での利用検証、実例、運用実績、写真・ブランド素材の拡充によってさらに価値を高められます。

- 資料中の「決済なし・静的のみ」は旧時点の方針として扱い、今回の直接依頼を優先してサーバー機能を追加しました。

- 架空の実績、評価、顧客数、営業日、事業者住所を作っていません。

| 対象 | 課題 | 改修内容 |
|---|---|---|

| 写真 | 写真と説明の役割が曖昧 | 提供済み画像を制作・整理のイメージとして配置。実際の制作現場・実績写真とは表示しない |
| 料金 | 範囲・費用・条件を読み比べにくい | 4プランを同じ重みで比較。追加作業、納期の起算、修正1回の意味、管理費別契約を明示 |
| 相談 | 外部フォームURLが未確定 | サイト内のヒアリングシートを作成。確認・修正・送信・受付番号・エラー状態を実装 |

| 画像処理 | 多数の遅延画像を先行展開 | 全画像の先行展開呼び出しを停止。ブラウザ標準の遅延読み込みを利用 |
| 決済 | 導線・実接続なし | 4つの支払い確認画面、見積専用リンク、金額照合、Shopifyカート作成、署名検証Webhookを実装 |

| 返金表現 | 提供MDに一律返金不可・当方不備時の上限80%という条件 | 完了作業・合理的費用の明細による精算と未実施分返金へ修正。消費者の法定権利を排除しない文案に変更 |
| 法務ページ | 旧外部フォーム前提・実装との不一致 | 規約、個人情報、特商法ページを今回の保存・予約・決済構成に合わせた草案へ更新 |

## 本番までに残ること

1. 税区分、正式氏名・住所・電話・メール、返信目安、保管期間等を確定し、表示と運用を一致させる。
2. 「事業者用・カスタマー用」が事業目的／一般消費者の区分でよいかを確定する。当方控え／お客様控えを意図していた場合は、同一契約の控え2部へ文書構成を変更する。
3. 弁護士等へ8草案と個別条件を提示し、実際の業務に適した最終契約文へ確定する。
4. Shopify・メールを接続し、テスト注文・通知・注文照合を通しで確認する。Shopifyの契約者・手数料・支払い方法は実ストアで確認する。
5. 運営者が実際の予約枠を登録し、参加URLを案内する運用を決める。
6. スマートフォン・PCでの画面確認と実際の対象顧客による診断・相談の利用検証を行う。
7. 本人確認済みの実績や、見本と明示した制作例を追加する。今回、架空の受注実績は追加していない。
