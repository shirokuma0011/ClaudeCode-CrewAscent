# クルーアセント 本体サイト

小規模事業者向けのWeb制作事務所サイト。全21ページ。
外部ライブラリ・CDN・外部フォント・外部画像は一切使っていません。

**このサイトはまだ公開できません。** → `公開前チェックリスト.md`

---

## 開くとき

ローカルで開く場合、ファイルを直接ダブルクリックするのではなく、
簡易サーバー経由で見てください。診断の保存機能が正しく動きます。

```
cd crew-ascent
python3 -m http.server 8000
# → http://localhost:8000/
```

## ファイルの構成

```
crew-ascent/
├── index.html ほか 21ページ
├── assets/
│   ├── css/
│   │   ├── base.css      トークン、書体、素地、版面、ボタン、ヘッダー、フッター
│   │   ├── system.css    章の面、章の入口、図版、写真の帯、一覧、表
│   │   ├── top.css       index.html だけの部品
│   │   └── styles.css    各ページ固有の部品
│   ├── js/
│   ├── fonts/            自己ホスト（OFL-1.1）
│   ├── img/  brand/  og/
├── data/works.json       見本サイトの一覧（現在は空）
└── tools/                原稿の一括置換・検査に使ったスクリプト
```

### CSSの読み込み順

```
base.css → system.css → top.css       （index.html）
base.css → system.css → styles.css    （その他20ページ）
```

**トークンの正本は `base.css` です。** 色や寸法を変えるときはここだけを触ってください。
`--ink` を1行変えれば、全21ページの濃色面が変わります。

---

## 触るときの注意

1. **`.sec--ink`（濃色面）に何か足したら、文字色を確認してください。**
   淡色面用の色が残ると読めなくなります。過去に 1.03:1 まで落ちた事故があります。
2. **要素をいったん透明にする作り（`opacity: 0` の初期値）は使わないでください。**
   打ち消し規則と対でしか成立せず、片方が消えると本文が全ページで見えなくなります。
3. **`.container` はJavaScriptも生成しています。** HTMLだけ改名すると診断が壊れます。
4. **原稿を大きく変えたら、書体のサブセットを作り直してください。**
   未収録の漢字はOSの既定フォントで表示され、字面が浮きます。
   手順は `assets/fonts/README.txt` にあります。
