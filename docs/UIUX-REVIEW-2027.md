| 評価項目 | 改修前の評価 | 観察した問題 |

| 文字・視線の流れ | 45/100 | スマホの本文14px、補助文8〜11px。下層には大きな飾り英字と長い説明があり、日本語の重要度が下がる。 |
| 比較・選択のしやすさ | 40/100 | トップの4問診断と詳細説明が長い。料金4プランも全詳細の縦積みで、入口と判断材料が混在。 |

UI/UXの総評は約40点。料金・診断・相談・契約・予約の土台は活用できるが、その内容を整理して見せる設計が不足していた。

## 今回のデザイン

コンセプトは「事業の方向を、一緒に見つける」。温かい白、深いグリーン、行動を示すブルーを基調に、36タイプを示す6×6の図形を固有のビジュアルにした。流行を示すためだけの動きや、事実のない実績表示は追加していない。

トップを、事業への姿勢 → 診断の4視点 → 料金 → 制作の流れ → FAQ → 2つの相談方法、の順に再構成。4問の暫定診断をトップから外し、16問・84問の本診断に集約した。料金はトップで短く比較し、詳細ページでは2列・スマホ1列で作業範囲を確認する。

全74ページに共通の書体・色・間隔・ボタン・ヘッダー・フッターを適用。下層の巨大な飾り英字を省き、固定ヘッダー時代の余分な上余白を除去した。本文16pxを中心に、補助情報は12〜14pxで構成する。

### 操作面の改修

- 診断：開始方法を先に提示し、詳細説明は開閉式に。進捗表示は残し、回答中のタイプ表示が画面を占有し続けない配置にした。中央回答時の結果文は「失敗」の印象を避ける表現へ変更。
- ヒアリング：相談内容・名前・メール・利用目的を先に。事業詳細9項目は任意で開く。プランや診断を引き継ぐリンクでは任意欄も開く。確認画面では空の任意項目を省き、先頭へスクロールする。入力修正で内容を保持。
- タイプ一覧：キーワード検索と4領域の絞り込み。全角英数字も検索可能。0件の説明、結果件数、解除操作を用意。
- 予約・決済：フォーム16px、カレンダーの日付は高さ44px、時刻ボタンは48px以上。月送り・受付状況・支払概要を読みやすく整えた。
- ナビ：拡張子あり・なしのURLで現在位置を認識。タブレット幅でもメニューを使用でき、Escapeで閉じて見出しへフォーカスを戻す。

## 公開に必要な情報

デザインで実績や事業者情報を作ることはできない。正式な運営者情報、価格の税区分、実在の制作実績、運用連絡先が揃うと、信頼性をさらに高められる。現在は所有者限定の確認サイト。既存の本番受付・決済停止条件、契約書の草案表示を維持する。

Shopifyの本番接続、メール送信設定、税区分、契約書の確認、実際の予約枠公開は未完了。詳しくは `LAUNCH-SETTINGS.md` と `OPERATIONS.md` を参照。
