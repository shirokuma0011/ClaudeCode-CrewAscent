# 相談アンケート（サイト内の2ページ）

作成日: 2026-10-15（同日、Googleフォームをやめ、サイト内のアンケートページに変更）

Googleフォームは使わず、**サイトの中にアンケートページを2つ**用意しました。

| | A. 相談アンケート | B. 事前ヒアリング |
|---|---|---|
| ページ | `consult-form.html` | `hearing-form.html` |
| 向いている人 | サイトのイメージが**まだ固まっていない**方 | サイトのイメージが**固まっている**方 |
| 形 | 1ページに15問・約5分 | 16の段階に分けて1段階ずつ・約20〜30分（条件で段階や質問を飛ばす） |
| サイト上の入口 | 全ページの「相談アンケートを開く」・相談ページ | 相談ページの「事前ヒアリングを開く」 |

## しくみ

- 設問の正本は `data/questionnaires.json`。直したら `npm run questionnaires` でページを作り直す（HTMLは直接直さない）
- 必須は**名前・事業者名・メール・同意**だけ。ほかは空欄で送れる
- 入力の途中は**この端末にだけ**下書きとして保存（30日）。再読み込みしても、続きから書ける
- 診断の結果（`?type=` か、この端末に残る結果）があれば、タイプの欄に最初から入る
- 最後に確認画面を出し、各段階の「修正する」で戻れる

## 送り方（回答がどう届くか）

確認画面のあと、次のどれかで送ります。サイトそのものは、何も送信しません。

1. **メールアプリで送る**（標準）… 宛先は `data/publish-values.json` の `email`。件名と回答が入った状態でメールアプリが開く。
   回答が長いとき（事前ヒアリングなど）は、本文をコピーしてから開くので、貼り付けて送る
2. **回答をコピーする** / **テキストで保存する** … 控えを残す。メールに貼る・添付する
3. **この内容で送信する**（任意）… PHPが動くサーバーに `server/questionnaire-mail.php` を置き、
   `site-config.js` の `formEndpoint` を設定したときだけ出る。回答がそのままメールで届く（`server/README.md`）

`email` が未確定の間は「メールアプリで送る」は押せません（「回答をコピー」「テキストで保存」は使えます）。
**`email` を決めて `npm run publish:apply` を実行すれば、アンケートからの相談を受け付けられる状態**になります。
