# 契約と情報管理

ここでは資料の内容と決定履歴を整理します。法律・税務・各サービス規約の最新解釈を今回新たに確定したものではありません。

## 契約書資産

9/9の直接依頼で、4プラン×事業者/カスタマーの計8パターンと4決済画面を要求。UIUX別案にHTMLとMarkdownの8草案があります。「事業目的/一般消費者」を区分と仮定しており、当方控え/顧客控えの2部を意味していた場合は構成を変更する必要があると運用資料に残ります。

草案を署名済み・専門家確認済み・法的有効性保証と扱いません。見積には制作範囲、納期の起点、顧客の提出・確認、修正1回の定義、追加作業、検収、支払、公開・管理、移管、素材の権利、実績掲載許諾等を一致させる必要があります。

## 返金条件の変遷

旧統合資料には「着手金返金不可」「当方不備でも着手金の最大80%」という表現がありました。9/9改修では完了作業・合理的費用の明細による精算、未実施分返金、消費者の法定権利を排除しない草案へ修正したと記録。8/25の管理契約整理には顧客都合原則返金なしと法令上・当方都合の例外を置く案があります。異なる契約種別の条件を一文に統合せず、最新の正式契約を確認します。

## 10/25の保管期間（PR案に反映）

| 情報 | 期間 |
|---|---|
| 成約しなかった相談・フォーム・メール・LINE | 最後の連絡から1年 |
| 契約案件の通常連絡・ヒアリング | 納品/保守終了の遅い方から2年 |
| 預かった写真・ロゴ・原稿等 | 納品から1年。保守で必要な分は保守終了まで |
| Zoom録画・録音・全文文字起こし・未確認AI要約 | 打ち合わせから90日 |
| 確認済み・顧客共有済み議事録/確認PDF | 納品/保守終了の遅い方から2年。ただし取引の合意を記録した文書は下段へ |
| 契約・見積・請求・発注等の取引書類 | 関係法令の期間。一般連絡とは別管理 |

出典はPR `docs/RETENTION_POLICY.md`。同文書は10/25本人承認と記載します。関連レビュー会話のアシスタントによる同意文をユーザーの承認そのものと取り違えず、実際の決定根拠はPR内部基準の記録として保持します。

月1回の期限超過削除は「予定、まだ実施していない」。実施開始日・削除記録を残す必要があります。Zoom上の記録だけでなくダウンロード分・自動要約メールも対象。紛争対応・法令保存の例外は理由と対象を限定し記録。AI要約を人が確認してから正式議事録とする方針です。

## LINE/Zoomの境界

LINE画面のトーク保存期間はLINEヤフーの仕様に依存するため、自社の保管予定期間と同じではありません。内部基準は無料時6か月と2026-10-25確認した記録を持ち、長く必要な要点は確認PDF/議事録へ移す案。今回、そのサービス仕様を再調査したわけではありません。

Zoomの録画・文字起こし・AI要約を使う方針。事前説明と同意、目的、保存・削除、共有先を整えます。参加者へ送られた要約メールを当方が削除できるわけではない点も説明する案です。会社名はZoom Communications, Inc.へ修正。LINEは友だち追加で何でも取得できるように書かず、当方が閲覧可能な範囲のプロフィールや本人が送った内容に限定します。

外部サービス名・公式ポリシー・処理目的を第5条等に反映し、外国への提供に当たるかは契約・設定を確認して判断する課題が残ります。各社規約へのリンクを置くだけで対応完了とはしません。

## 税務情報と未確定

8月文書はインボイス登録予定。10/25PRの公開値には「登録していないため発行できません」、内部基準にも現状登録しない旨があります。登録番号を捏造せず、過去の予定を現状として扱いません。

事業形態・申告方法が未確認のため、具体的な法定保存年数と起算日をクルーアセント向けに一律確定しません。過去のレビューに青色/白色/法人/インボイスの期間表がありますが、正式運用は該当性と起算日を確認して決定する必要があります。契約の合意を含む確認PDFを単純に通常連絡扱いの2年で削除しない点が後続修正です。

## 機密とAI

公開リポジトリには実設定、鍵、APIトークン、管理者パスワード、実データ、署名済み書類を入れない。顧客の認証情報・個人情報を生成AIへ無制限に渡さないという過去方針があります。生成AIサービスの具体名を営業面に出すかと、法的な外部処理説明を省けるかは別問題です。
