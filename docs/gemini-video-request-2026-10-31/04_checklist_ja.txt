# 動画の受入チェック

生成AIの自己申告ではなく、保存したMP4を再生して確認します。

| 項目 | 合格条件 |
|---|---|
| ファイル | 実際に再生できるMP4、8秒、横16:9、音声なし |
| 解像度 | 希望1920×1080。実出力を確認し、異なる場合は記録 |
| カメラ | 冒頭・中間・末尾で固定。パン・ズーム・回転なし |
| 台 | 角や端の位置が変わらない |
| タイル | 全時間を通して6×6=36枚、ブラウン1枚 |
| 静止部分 | 35枚のタイルがずれず、伸び縮みしない |
| 動く部分 | ブラウン1枚だけがわずかに上下し、元の場所へ戻る |
| 光 | 左から右へ滑らかに通過。明るさが突然変わらない |
| ループ | 最初と最後の場面・露出が一致。連続3回再生して跳ばない |
| 禁止物 | 人物・手・文字・数字・ロゴ・余計な小物なし |
| 掲載方法 | 生成した静物イメージとして使用。実在の事務所映像と誤認させない |

最低限、0秒・2秒・4秒・6秒・終了直前を静止して比較してください。画角を固定し、ブラウンの上下動を除く部分を半透明で重ねると位置ずれを発見しやすくなります。

静止画6枚を並べただけのスライドショーは、今回の動画の合格条件を満たしません。
