# 個人情報の保管期間（内部基準）

2026-10-25 決定（本人承認）。プライバシーポリシー第8条と `data/publish-values.json` の `retentionPolicy` はこの表と同じ内容にする。
個人情報保護法に一律の保存年数はなく、利用する必要がなくなった個人データは遅滞なく消去するよう努める、という考え方に基づく。

| 情報の種類 | 保管期間 |
|---|---|
| 契約に至らなかった相談・フォーム回答・メール・LINEトーク | 最後の連絡から1年 |
| 契約した案件の通常のメール・LINEトーク・ヒアリング回答 | 納品または保守契約終了の遅い方から2年 |
| 顧客から預かった写真・ロゴ・原稿などの制作素材 | 納品から1年。保守で必要なものは保守終了まで |
| Zoomの録画・録音・全文文字起こし・未確認のAI要約 | 打ち合わせ日から90日 |
| 内容を確認し、顧客と共有した議事録・確認PDF | 納品または保守契約終了の遅い方から2年 |
| 契約書・見積書・請求書・発注書など | 通常のやり取りと分け、関係法令に定める期間 |

## 運用（予定。まだ実施していない）

- 月1回、期限を過ぎた情報を削除する。始めたら、この節に開始日を書く
- 削除の対象には、Zoom などのサービス上の記録だけでなく、ダウンロードした記録、自動で届いた要約メールも含める
- 紛争対応や法令上の保存が必要な情報は、理由と対象を限って例外として保管し、その理由を記録する
- AI要約は、内容を確認してから正式な記録（議事録）として扱う

## 未確定

- 契約・税務書類の具体的な保存年数：事業形態（法人か個人事業か）に応じて税理士などに確認し、確認後にこの表へ反映する
- LINE公式アカウントのトークは、管理画面での保存期間が LINEヤフー の仕様で決まる（無料のままでは6か月。公式マニュアルで 2026-10-25 確認）。長く残す必要がある内容は、確認PDF・議事録に移す
- Zoom の要約メールは参加した顧客にも届くことがあり、当方では削除できない。録画・文字起こし・AI要約を使う前の説明に入れる
