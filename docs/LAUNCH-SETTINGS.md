# 本番開始のための確定事項

以下は推測で埋めていません。未確定でもサイトと各画面は確認できますが、決済は停止しています。

| 項目 | 現在 | 必要な対応 |
|---|---|---|
| 8万・12万・15万・22万円の税区分 | 未回答 | 税込／税別を確定し、すべての表示・契約・商品金額を一致させる |
| 契約書の2区分 | 事業目的／一般消費者と仮定 | 事業者控え／お客様控えを意味する場合は同一書面2部へ修正 |
| 正式事業者情報 | 未提供 | 氏名・法人名、代表者、所在地、電話、メールを記入 |
| 返信と営業の案内 | 未確定 | 営業日、返信目安、対応地域、相談の連絡方法を確定 |
| 契約条件 | 草案 | 対応ブラウザ、納品形式、検収期間、納期、税、管轄等を確定して専門家確認 |
| 公開・管理 | 任意の別契約 | ドメイン費、更新・解約、返金、データ移管条件を確定 |
| 個人情報 | 確認用草案 | 保管期間、削除、問い合わせ受付、実際の外部サービス情報を確定 |
| Shopify | 未接続 | ストア、8バリエーション、トークン、Webhook、チェックアウト条件を設定 |
| メール | 未接続 | 通知サービス・送信ドメイン・差出人・運営宛先を設定 |
| 相談予約 | 実際の空き枠なし | 管理画面で実際に対応できる日時を登録。参加方法を案内 |
| 公開先 | 所有者限定の確認用 | 公開ドメイン・一般公開可否を決定。承認なく一般公開しない |
| 実績 | 架空の実績は追加なし | 許諾済みの実績または見本と明示した制作例を用意 |

設定後は、受付・予約・取消・メール到達・契約の確認・テスト注文・入金反映を、本番と同じ構成で通し確認します。全ページのnoindex解除は、情報確定と確認後に対象ページのみ行います。結果ページ・管理画面・個別決済・本人取消画面・契約書の草案は検索対象にしません。
