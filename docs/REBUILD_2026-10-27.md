## 5. ABeam（オーナーの録画から。2026-10-27）

録画は 1920 幅の画面。値はコマから読んだ近似値。

| 項目 | 値 |
|---|---|
| 地の色 | 黒 #000（トップのほぼ全面）、生成り #EEE9E1 の面が1か所、フッターは濃い灰 |
| 差し色 | ブラウン #7B6B5A（特集の帯、「Learn more」「View more」のボタン、点描の波） |
| 見出し | 明朝の太字。章の英字見出し「News」は約 96px、主張の一文は約 44px |
| 本文 | ゴシック 約 17px / 行間 約 1.9、白文字 |
| 余白 | 左右 100px、内容の幅 約 1,700px |
| ヘッダー | 黒・2段（小さな補助メニュー＋大きな主メニュー 約 22px）、高さ 約 135px |
| 部品 | 角丸なし。線だけの四角いボタン、写真を大きく使う、一覧は 1px の罫線で区切る |

これを受けて、トップに比較案B（`?look=b`）を作った。黒の地、見出しだけ明朝（Noto Serif JP 700 を
サイト内の 1,448 字に絞って自前で配る。CASerif-700.woff2 約 230KB）、差し色はブラウン。
地図・文言・構成はA案と同じで、色と書体だけが違う。PC 3,959px / スマホ 6,375px。
