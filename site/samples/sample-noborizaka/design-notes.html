「週2回で体力をつくる パーソナルジム のぼりざか」の設計メモ

この見本は架空の事業です。Web診断36の CA03 成長サービス型サイト の方針を、パーソナルジムの事業に当てはめるとどうなるかを示すために作りました。

01このタイプの方針

サービスの成長性と行動までの流れを結び、次の一歩を作るタイプです。情報の分かりやすさを保ちながら、導入後の変化や将来像を前向きに伝えます。新規事業、成長支援、継続サービスなど、相談や申込みへ進む理由を具体化したい場合に向きます。

位置実用・情報 × 先進・新しさ
横軸 3 / 6（やや情報寄り）— 要点の絞り込み
縦軸 6 / 6（もっとも先進寄り）— 未来感と実験性
デザインの言葉上昇感機敏明るい余白斜めの経路根拠付き数値

02最初の画面の4つの役割と、この見本での答え

方針この見本では
見出しの役割
何をする事業かを一行で言い切り、余計な前置きを置かない		「週2回・1回50分。体力を、坂道のように少しずつ。」の一文で、何をするジムか（体力づくり）と、通い方（週2回・50分）を前置きなしで言い切りました。窓の光が差す小さなジムの写真を画面いっぱいに敷き、左の静かな側に見出しを重ねています。
添える情報
主なサービス、料金の目安、連絡方法を三つ以内に絞って示す		見出しの下に、主なサービス（トレーナーと1対1の練習）／料金の目安（週2回 月35,200円、体験3,300円）／連絡方法（フォーム・電話 10〜20時）の3つだけを、細い罫で区切って並べました。
裏づけ
対応できる範囲と、できない範囲を並べて置く		最初の画面のすぐ下の2章で、このジムですること（基本の筋力・歩く練習・記録）と、しないこと（医療的なリハビリ、極端な食事制限、体型の変化の約束）を左右に並べています。
主な行動
「問い合わせる」を主要な行動として置き、その近くに現在対応できる範囲、相談の流れ、決まっていない段階でも相談できることを添える		「問い合わせる（体験の申し込み）」を黄緑の四角いボタンにして、見出しの下・ヘッダー・最後の章・スマホ下部の固定バーに置きました。すぐ下に「体験は50分。ウェアとタオルは貸し出します。回数や曜日が決まっていなくても相談できます」と添え、最後の章には「いま受けられること: 1対1の指導のみ」と返信の目安を書いています。

03情報の優先順位と、置いた場所

優先順位（方針）この見本で置いた場所
1. 何をする事業か最初の画面の見出しと、その上の一行「運動から長く離れていた40〜60代の、1対1のジム」
2. 主なサービスと料金の目安最初の画面の3つの事実と、4章「料金と、追加費用が出る条件」の2つの表（月謝・回数券）
3. 連絡方法と受付時間最初の画面の「連絡方法」と、6章の電話の受付時間・返信の目安
4. これから実現したいこと3章「3か月の進め方」。最初の面談→基礎の練習→自分で続ける練習を、15度の線でつながる3段で示し、3か月後に自分で続けられることを目標にしています
5. 現在提供できること2章「このジムですること」と、6章の「いま受けられること（1対1の指導のみ）」
6. 料金と、追加費用が出る条件4章の表の直下に、追加費用が出る2つの条件（ウェアの貸し出し1回330円、振替の期限）を置きました。入会金がないことは見出しの横に書いています
7. 問い合わせの方法と、その前に確認できること6章「体験の流れと問い合わせ」。体験の50分の内訳（10・15・20・5分）を時間の長さに比例した帯で示し、よくある質問3つのあとに問い合わせフォームと電話の受付時間を置きました

04見た目の判断

配色#FAFAF7 地の色（白い壁）
#111827 墨: 文字
#2D6A4F 深緑: 見出しの斜線・段階の番号・最後の章の地
#C8F031 黄緑: 主な行動のボタンと、上昇の斜線だけ
#E5E7EB 灰: 罫線
書体見出しは LINE Seed JP（Regular 400、小見出しだけ Bold 700）、数字は Archivo Italic（SemiBold 600）。どちらも SIL Open Font License の書体で、このページで使う文字だけに絞って fonts/ に置いています（3ファイル合計 約60KB、ライセンス文は fonts/OFL.txt）。外部の書体サービスは読み込みません。本文はOSのゴシックのままです。見出しは細めの端正なゴシックにして、数字だけを少し前に傾けたイタリックで「前へ進む」軽さを出しました。極太の見出しや筋肉を強調する表現は使っていません
署名モチーフ「坂の斜線」: 15度で右上へ上がる細い線。各章の見出しの下線、ロゴの2本線、ボタンの矢印、「このジムですること」の行頭、3章の3段をつなぐ黄緑の線を、すべて同じ角度でそろえています
骨格「全幅の写真と、斜めに上がる段」。写真を背景にした最初の画面 → 左に器具の写真・右にすること／しないこと → 21:9の写真の帯の上に3段が15度で上がっていく進め方 → 白地の2つの料金表 → 2枚の写真で挟んだ通いやすさ → 深緑の地の体験と問い合わせ。写真の面・白の面・深緑の面を交互に置いて緩急をつけています
署名の動き3章が画面に入ると、3つの段の角を結ぶ黄緑の斜線が、左下から右上へ1回だけ引かれます（transform、約1.7秒、1回）。ほかは動かしません
動きを減らす設定では斜線ははじめから引かれた状態です。JavaScriptが動かない環境でも同じです
方針からの調整方針の「白または濃色を主役に」は、白い壁の色を主役にし、最後の章だけ深緑の地にしました。黄緑は文字色としては読めないため、ボタンの地と斜線にだけ使い、ボタンの文字は墨にしています。補足の文字色 #4B5563 は墨を淡くした派生色です。1ページの見本のため、ページの高さはPCで約4,300px、スマホで約6,400pxに収めました。

05あえて避けたこと

  • 情報を足しすぎて、結局どこを読めばよいか分からなくなる
  • 同じ内容を言い換えて何度も繰り返す
  • 構想の説明が先に立ち、いま何を頼めるのかが分からない
  • 掲載できる事実がないまま、実績や利用者の声を作って載せる
  • 体型の変化の写真や、「必ずやせる」などの効果の断定
  • 筋肉を強調した写真や、極太の文字で勢いをつける表現
  • 入会を急がせる期間限定のキャンペーン表示

06実際の制作で変わること

  • 写真: 見本の写真（ジムの床・器具のラック・3つの木の台・記録ノート・更衣スペース）はAI生成のイメージで、実在の店舗ではありません。人物は写していません。実際の制作では、事業者の店内を撮影した写真、または許可を得た写真に差し替えます
  • ロゴ: 実際の制作では、事業者のロゴを使います（この見本の「のぼりざか」のロゴは見本用の簡易なものです）
  • 価格・受付時間: 事業者が確定した値を載せます。料金の改定日を表の下に書きます
  • 問い合わせ: 事業者が使っている予約サービスやフォームへつなぎます（見本ではダイアログを出すだけです）
  • 健康に関する表現: 医療的な効果をうたわず、持病のある方には主治医への確認をお願いする書き方にしています
  • 書体: LINE Seed JP と Archivo は OFL の書体を使う文字だけに絞ってサイト内に置いています（外部の書体サービスには接続しません）。文章を直したら、文字の絞り込みを作り直します
  • 所在地・電話番号: 見本のため載せていません
