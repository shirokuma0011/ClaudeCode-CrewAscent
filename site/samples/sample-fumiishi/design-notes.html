「ものづくり企業の特許・意匠・商標 ふみいし特許事務所」の設計メモ

この見本は架空の事業です。Web診断36の CA35 高信頼ブランド型サイト の方針を、特許・知財事務所の事業に当てはめるとどうなるかを示すために、トップ「事務所の案内」と下層「初回相談とお問い合わせ」の2ページで作りました。

01このタイプの方針

高い専門性とブランドの格を一体で示すタイプです。大きな責任、高額契約、機密性を伴う事業に向きます。資格、体制、実績、思想を端正にまとめ、選ばれるための信頼を長期資産として作ります。

位置ブランド・魅力 × 王道・安心
横軸 5 / 6（ブランド寄り）— 魅力と印象
縦軸 1 / 6（もっとも王道寄り）— 見慣れた構成と実直さ
デザインの言葉高信頼重心の低い版面精緻な文字深い色節度あるブランド演出
この見本の一文机の上の試作品を、収蔵品の目録のように番号で並べ、その番号が図面の符号と請求項の文になっていく道筋として見せる

優先順位（方針）この見本で置いた場所

05見た目の判断

配色#f5f3ef 生成り（地の色・明細書の頁）
#121a24 濃紺墨（文字・展示台・申し込みの帯）
#2b3a4f 深藍（「書類になるまで」の章）
#b39a5e 真鍮（暗い面の番号・細い線・申し込みのボタン）
#8a7653 古金（明るい面の細い線）
書体見出しは Noto Serif JP（SemiBold 600）、請求項の文・願書・覚書は Noto Serif JP（Regular 400）、目録番号と金額は Marcellus。どれも SIL Open Font License の書体を、この2ページで使う文字だけに絞って fonts/ に置いています（合計 約65KB、ライセンス文は fonts/OFL.txt）。外部の書体サービスは読み込みません。本文はOSのゴシックです
署名モチーフ「目録番号」と「踏み石」。どの章の頭にも No.1 のような目録番号を置き（数字の0と英字のOを見誤らないよう、0を頭に付けない番号にしています）、展示物には収蔵品の札を添えています。踏み石は、1本の真鍮の基線の上に、幅72px・厚さ5pxの平たい石を間隔をあけて並べたもので、トップでは章の順番（展示台の下端）、下層では申し込みから出願の準備までの5段を示します
骨格トップ: 暗い展示台（全面の試作品）の左下に生成りの明細書の頁を一枚置き、展示台の下端に踏み石 → 生成りの展示棚（大きさの違う3点を、下端をそろえて並べる）→ 深藍の面に、大きさの違うスケッチ・図面・請求項 → 相談室の写真を右へ裁ち落とし → 明るい面の費用の表 → 濃紺の申し込みの帯。
下層「目録の一点」: 暗い地に分解した歯車と軸を一点、右に h1 と要点3つを下寄りに → 踏み石の工程 → 暗い展示台の「持ってくるもの」→ 明るい面に覚書の見本 → 明るい面の入力欄
署名の動き踏み石が、画面に入ったときに一度だけ、左から順に灯ります（淡い石が真鍮の色になる）。ほかに動くものはありません
動きを減らす設定では踏み石ははじめから灯った状態のまま。ページ内の移動もなめらかなスクロールをやめます
方針からの調整方針の「彩度の高い色は行動の合図だけ」に合わせ、真鍮は番号・細い線・申し込みのボタンだけに使いました。深藍の面では、真鍮を少し明るく（#cdb680）してコントラストを保っています。方針の「白を基調」は、生成りの面を基本にし、暗い面は最初の画面・持ってくるものの目録・申し込みの帯に限りました。費用の表と入力欄は、どのページでも明るい面に置いています。見出しは h1 44px（下層 36px）・h2 28px、本文15pxです。初回相談の「60」と図面・請求項の符号は、0とOを見誤らないよう明朝の数字にしました。高さは、トップがPCで約5,150px・スマホで約7,000px、下層がPCで約4,500px・スマホで約6,500px（どちらも下の案内を含む）です。

06あえて避けたこと

  • 画像だけが続き、料金や対応範囲にたどり着けない
  • 写真を暗くぼかして、何の事業か分からなくなる
  • 珍しい操作方法を使い、戻り方が分からなくなる
  • 掲載できる事実がないまま、実績や利用者の声を作って載せる
  • 「必ず特許が取れる」など結果を約束する言葉
  • 特許証・図面・書類の文字が読める写真、実在の製品に見える形（図面と書類は、架空の例であることを書いたうえで HTML と SVG で描いています）
  • 特許庁の費用を含まない金額だけを見せること
  • 番号の丸い印や、同じ大きさの枠を並べたボタンのような案内
  • 相談のあとの下調べを、無料と言い切ったり、権利が取れると読める書き方

07実際の制作で変わること

  • 図版: 見本の写真（試作品・部品・取っ手・相談室・スケッチ）はAI生成のイメージで、実在の事務所や製品ではありません。人物は写していません。実際の制作では、事務所の写真と、許可を得た試作品の写真に差し替えます
  • 図面・請求項・商標登録願・秘密保持の覚書: 見本では架空の例として描いています。実際の制作では、事務所が公開してよいと判断した書面の見本に差し替えます
  • 資格者の氏名・登録番号: 実際の制作では正確に載せます（弁理士の広告の決まりに沿って）
  • 特許庁の費用: 法令で定められた金額を載せ、改定に合わせて直します。事務所の手数料は事務所の料金表によります
  • 所在地・電話番号: 見本では架空の地名と番号です。実際の制作では、電話番号は押すと電話がかかるリンクにし、地図は画像と地図アプリへのリンクにします
  • 問い合わせ: 事務所が使っているフォームへつなぎます（見本ではダイアログを出すだけです）。個人情報の扱いのページを作り、フォームからリンクします
  • ロゴ: 実際の制作では、事業者のロゴを使います（この見本のロゴタイプは見本用の簡易なものです）
  • 書体: OFL の書体を使う文字だけに絞ってサイト内に置いています（外部の書体サービスには接続しません）。文章を直したら、文字の絞り込みを作り直します
