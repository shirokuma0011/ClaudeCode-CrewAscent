「完全予約制のフェイシャルとボディ サロン しずり」の設計メモ

この見本は架空の事業です。Web診断36の CA23 上質魅力型サイト の方針を、エステ・リラクゼーションの事業に当てはめるとどうなるかを示すために作りました。

01このタイプの方針

安心して選べる情報に、上質な魅力を重ねるタイプです。価格が比較的高く、品質や体験への納得が必要な事業に向きます。落ち着いた写真、素材、言葉で価値を見せつつ、料金や流れも隠しません。

位置ブランド・魅力 × 王道・安心
横軸 5 / 6（ブランド寄り）— 魅力と印象
縦軸 3 / 6（やや王道寄り）— 丁寧さと親切さ
デザインの言葉上質静かな余白素材感深い中間色ゆっくりしたリビール

03ページと、情報を置いた場所

ページ・優先順位（方針）この見本で置いた場所
トップ（サロンと施術）雰囲気を感じ取り、何をいくらで受けられるか、来てから帰るまでどう過ごすかを確かめるページ。主役は「分の長さに比例した写真の帯」です。帯の写真は、近くの大きな写真と同じ絵にならないよう、各写真の一部分（瓶の肩・リネンの光・湯のみの縁・たたんだタオル）を拡大しています
下層（ご予約と当日まで）予約の方法・空きの確かめ方・予約から当日までの流れ・空きの問い合わせ欄のページ。主役は「予約表の画面」と「日にちの軸の流れ」と「問い合わせ欄」です
下層にこのページを選んだ理由完全予約制で一日四名までの事業では、予約の方法・空きの確かめ方・キャンセルの扱いが申し込みの直前の一番の不安になるため、Reservation を代表の下層にしました。
1. 事業の雰囲気が伝わる主役の一枚トップの最初の画面の、障子越しの光が入る個室の写真
2. 何を提供しているか最初の画面の料金の罫（三つのメニュー）と、「ふたつの施術と、季節のオイル。」（施術の中身とオイルの選び方）
3. 興味を持った人が次に見るもの「施術のあと」の暗い写真の章（白湯と十五分の休憩）
4. 初めての人向けの説明「来てから帰るまで、約二時間です。」— お話・着替え・施術・白湯と休憩・身支度の五つの場面を、かかる分の長さに比例した幅の写真で並べ、全体の目安を下に
5. よくある質問トップの「料金とよくある質問」に4問（勧誘の有無・メイク・香り・男性の利用）を2列で
6. 費用の考え方「料金に、ぜんぶ含まれます。」— 籠のガウン・タオル一式の写真と、含まれるもの・追加の料金・初めての方・お支払い・キャンセルの細い罫
7. 問い合わせの方法と、その前に確認できることトップの料金の章の終わりの一行の帯（「ご予約は、Webの予約表・お電話・メールで。」）から、下層の「ご予約と当日まで」へ。下層で予約の三つの方法、予約表の見方、予約から当日までの流れ（各段階に用意するもの）、問い合わせ欄（メニューごとの時間と税込料金つき）を確かめられます

骨格トップ：障子を引き寄せた最初の画面 → 文字の列と右へはみ出すオイルの写真 → 分の長さの写真の帯 → 暗い写真に小さな言葉（施術のあと）→ 籠の写真と含まれるものの罫・よくある質問・予約の一行の帯。下層：暗い写真に小さな h1 と、写真の下の罫の中の要点3つ → 予約の三つの方法 → 予約表の画面 → 日にちの軸の流れと着替えの写真 → 問い合わせ欄 → 次に読むページ
道しるべ「余白の小さな章名」：広い画面では、各章の名前を左の余白に小さく縦に置き、同じ言葉の小見出しは出しません（狭い画面では小見出しに戻します）。予約の入口は、どの章の終わりも同じ細い枠のボタンです
署名の動き最初の画面で障子の面が約1.9秒かけて少し引かれ、章の写真と言葉は約1.5秒かけてゆっくり現れます（1回だけ）。それ以外に動くものはありません
動きを減らす設定では障子の面も要素も最初から表示し、動きはありません
方針からの調整方針の「白を基調に、緑や青緑を案内と完了に」は、障子紙の生成りを地に、案内を深い灰褐の細い枠にしました。強い色は使いません。灰茶（#8c7a66）は小さな文字には足りないため罫と枠にだけ使い、補足の文字は #594d43 にしています。方針の注意「高級感のために文字を小さくしたり、情報を隠したりしない」に合わせ、本文は15〜15.5px、補足は13px以上、料金は最初の画面に全部出しています。見出しは h1 40px・h2 29px・下層の h1 32px までに抑えました。高さはトップがPCで約4,600px・スマホで約6,300px、下層がPCで約4,300px・スマホで約6,300pxです。

05あえて避けたこと

  • 画像だけが続き、料金や対応範囲にたどり着けない
  • 写真を暗くぼかして、何の事業か分からなくなる
  • 説明を長くしすぎて、結局どこから始めればよいか分からなくなる
  • 掲載できる事実がないまま、実績や利用者の声を作って載せる
  • 効果効能の断定（「小顔になる」「痩せる」など）と、施術前後の比較写真
  • 塗りの大きなボタンや、明るい原色
  • 期間限定の割引や、初回だけの値引きで急がせる書き方

06実際の制作で変わること

  • 図版: 見本の写真（個室・オイル・着替え・白湯・洗面）はAI生成のイメージで、実在のサロンではありません。人物は写していません。各ページに一度、その旨を書いています。実際の制作では、事業者のサロンを撮影した写真に差し替えます。予約表の画面は HTML で描いた例です
  • ロゴ: 実際の制作では、事業者のロゴを使います（この見本の「しずり」のロゴタイプは見本用の簡易なものです）
  • 価格・営業時間・住所・電話・メール: 事業者が確定した値を載せます。番地・電話・メール・当日のキャンセルの扱い・予約枠の時刻・個人情報の扱いは【要確認】にしています。実際の制作では、プライバシーポリシーのページを用意します
  • 予約・問い合わせ: 事業者が使っている予約サービスやメールへつなぎます（見本ではダイアログを出すだけです）
  • エステは医療ではないため、効果効能を断定する言葉（治る・痩せる等）を使わず、施術の内容と時間・料金だけを書いています（景品表示法・医薬品医療機器等法の観点）
  • 書体: 文章を直したら、文字の絞り込みを作り直します
