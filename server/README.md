# 相談アンケートの受け口（任意）

`site/consult-form.html`（相談アンケート）と `site/hearing-form.html`（事前ヒアリング）は、
**このフォルダのファイルを置かなくても使えます。** その場合、確認画面のあとに
「メールアプリで送る」「回答をコピーする」「テキストで保存する」が出ます（宛先は `data/publish-values.json` の `email`）。

公開サーバーで **PHP が動く**場合（さくらのレンタルサーバなど）は、ここのファイルを置くと、
アンケートの「この内容で送信する」ボタンから、そのまま回答がメールで届くようになります。

## してくれること・しないこと

| する | しない |
|---|---|
| 回答を、決めたアドレスへ1通送る | 回答をサーバーやデータベースに保存する |
| 返信先（Reply-To）を回答者のメールにする | 回答者へ自動返信する（他人のアドレスで迷惑メールを送らせる悪用を防ぐため） |
| 同じサイトのページ以外からの送信を断る | 外部サービスへ送る |
| 見えない欄・送信までの時間でボットを止める | 画像認証などの外部サービスを使う |
| 同じ送り元からの連続送信を1時間あたりで制限する | |

## 置き方

1. `questionnaire-mail.config.sample.php` をコピーして `questionnaire-mail.config.php` にし、値を書き換える
   - `to` … 回答を届けるアドレス（`data/publish-values.json` の `email` と同じ）
   - `from` … 送り元。**サイトと同じドメイン**のアドレス（例: `no-reply@crewascent.com`）。違うドメインだと迷惑メール扱いされやすい
   - `allowedOrigins` … `['https://crewascent.com', 'https://www.crewascent.com']`
2. 公開サーバーに `api/` フォルダを作り、`questionnaire-mail.php` と `questionnaire-mail.config.php` を置く
   （設定ファイルはPHPとして動くので、URLを開いても中身は表示されません）
3. `site/assets/js/site-config.js` の `formEndpoint` を `'/api/questionnaire-mail.php'` にして公開し直す
4. アンケートを自分で1回送り、**メールが届くか**を確かめる（迷惑メールフォルダも確認）

`formEndpoint` が空に戻れば、いつでも「メールアプリで送る」に戻ります。
送信に失敗したときも、画面には「メールアプリで送る」「回答をコピー」が残るので、回答は失われません。

## 確かめたこと（2026-10-15、ローカルのPHPで）

正しい送信でメールが1通届くこと、件名の日本語、返信先、送り元に加えて、次を確かめました（11項目すべて合格）。
- 見えない欄に入力があるとき・開いてから5秒未満のときは送らない
- ほかのサイトからの送信を断る
- ヘッダーの差し込み（Bcc を作らせる）を防ぐ
- 1時間の上限を超えると断る
- GET・大きすぎる本文・JSON以外を断る

ブラウザで相談アンケートに答えてから送信し、届いたメールを読めることまで確かめています。
実際のサーバー（さくらのレンタルサーバ等）での送信は未確認です。置いたあと、必ず1回試してください。
